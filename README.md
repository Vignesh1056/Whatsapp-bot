#  WhatsApp Bot

A simple WhatsApp bot project built to explore WhatsApp automation, messaging APIs, and chatbot development.

---

##  Overview

This repository was created as an experimental project to learn how WhatsApp bots work and to explore the technologies involved in building automated messaging applications.

The project serves as a playground for testing ideas related to:

- WhatsApp automation
- Bot development
- Message handling
- API integration
- Event-driven programming

---

##  Features

- Basic WhatsApp bot setup
- Automated message handling
- Easy to extend with new commands
- Modular project structure
- Suitable for experimentation and learning

---

## Tech Stack

- **Runtime:** Node.js
- **Library:** [whatsapp-web.js](https://github.com/pedroslopez/whatsapp-web.js) / [Baileys](https://github.com/WhiskeySockets/Baileys) *(or your preferred engine)*
- **Language:** JavaScript / TypeScript

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Vignesh1056/Whatsapp-bot.git
```

### Navigate to the project

```bash
cd Whatsapp-bot
```

### Install dependencies

```bash
npm install
```

### Run the bot

```bash
npm start
```
